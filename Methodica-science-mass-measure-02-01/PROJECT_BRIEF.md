# PROJECT_BRIEF.md — לומדת "מדידת מסה" (720 | מדעים | כיתה ז')

## לקוח והקשר
משרד החינוך, תכנית 720 — פיילוט בינה מלאכותית להתאמה אישית בכיתות ז'.
מתודיקה מפתחת יחידות לימוד במדעים לכיתות ז'. הלומדה הנוכחית היא יחידת "מדידת מסה"
(שם התיקייה: `Methodica-science-mass-measure-02-020726`).

## מטרת הפרויקט
המרת עיצוב Figma ללומדה אינטראקטיבית עובדת ב-HTML5 + CSS3 + JavaScript טהור,
בנאמנות ויזואלית גבוהה ("Pixel Perfect" ככל האפשר), בעברית, RTL מלא, ללא תלות
ברשת (assets מקומיים בלבד, נתיבים יחסיים בלבד).

## היקף השלב הנוכחי
נבנים **שני מסכים בלבד** מתוך שני קבצי Figma נפרדים. מסכים/פריימים נוספים
(כולל פריימי "Screen 2 — State X" שקיימים בקובץ הראשון ועוסקים בבחירת נושא וידאו —
Breath/Feeding/Reproduction) **אינם בהיקף הנוכחי** ויתווספו בעתיד.

### מסך 1 — בחירת דמות מלווה (TwoOptionSelection)
**מקור:** Figma file `TFD8cGkfdxEXNAaFQH0aAc` ("Figma-Claude-Workshop"),
frames: `1:132` (Before Interaction), `1:141` (Hover), `1:150` (Selected).

- שתי דמויות ("Blue Character" / "Green Character") להצגה כרטיסי בחירה יחיד.
- מצבים: לפני אינטראקציה / hover / נבחר (selected). בחירה יחידה בלבד.
- לאחר בחירה — כפתור "בחרתי" הופך מפעיל (מ-disabled ל-enabled).
- לחיצה על הכפתור מעבירה למסך 2.
- הבחירה **להדגמת state בלבד** — אינה משפיעה על מסך 2 בשלב זה.
- הבחירה נשמרת ב-`window.lomdaState.selectedCharacter` (ערכים: `"blue"` / `"green"`,
  לפי שמות הרכיבים בפועל ב-Figma) לשימוש עתידי כשדמות תופיע במסכים הבאים.

### מסך 2 — שאלת בחירה יחידה עם תמונה (SingleChoiceQuestion)
**מקור:** Figma file `Z9sD0kksYj1Ph1kUcs71sw` ("לומדת התנסות"), frames:
- `196:3320` — State 01 לפני אינטראקציה
- `196:3445` — State 02 לאחר בחירת תשובה (לפני בדיקה)
- `196:3497` — State 03 משוב תשובה נכונה
- `196:3510` — State 04 משוב תשובה שגויה — ניסיון 1
- `578:9624` — State 05 משוב תשובה שגויה — ניסיון 2 (סופי)
- `196:3319` — כפתור "אפשר רמז?" (מצב bar כללי)
- `579:9740` — פופ-אפ רמז

מבנה: תמונת תוכן (placeholder ריק — אין תמונה אמיתית עדיין), טקסט שאלה, 4 אפשרויות
בחירה יחידה (radio pills), פס פעולה תחתון: **צדקתי? / אפשר רמז? / חזרה**.
שני ניסיונות מענה. אחרי הניסיון השני — משוב סופי מוצג ללא אפשרות ניסיון נוסף.
כפתור "אפשר רמז?" פותח פופ-אפ רמז (עיצוב כחול, כותרת+גוף+כפתור "חזרה לשאלה").

מיושם לפי סקיל `SingleChoiceQuestion.md` (720-templates), עם עדכון המידות/צבעים
למה שמופיע בפועל ב-Figma של הפרויקט הזה (ראו ARCHITECTURE.md לפערים מהתבנית הגנרית).

## דרישות מחייבות
- HTML5 + CSS3 + JavaScript בלבד. ללא React/frameworks/build tools/CDN חיצוני.
- RTL מלא מהשורש (`<html lang="he" dir="rtl">`).
- Assets מקומיים בלבד, נתיבים יחסיים בלבד.
- טקסט פונה-ללומד = HTML חי בלבד. אסור טקסט אפוי בתוך תמונה.
- אסור לייצא frame מלא (עם טקסט) כרקע (background).
- מיוצאים רק רכיבי איור/אייקון/רקע/צורה שאין בהם טקסט חי.
- Figma הוא מקור האמת (source of truth) לעיצוב; brief זה קובע התנהגות/אינטראקציה.
